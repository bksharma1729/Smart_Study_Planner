# Smart Study Planner

## 📌 Overview
Smart Study Planner is a responsive web application built with HTML, CSS, and JavaScript that helps students organize their study schedule, manage tasks, and improve productivity.

## 🚀 Features
- Add and manage study tasks
- Create structured study plans
- Responsive design
- Clean and intuitive interface
- Lightweight and fast

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## 📂 How to Run
1. Clone the repository
2. Open index.html in your browser

## 🎯 Future Improvements
- Add notifications/reminders  
- Dark mode  
- Progress tracking  
- Local storage / database support
